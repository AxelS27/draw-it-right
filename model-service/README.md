# One-click laptop inference for Draw It Right

From the project root on Windows, double-click **`start-model.bat`** and keep its window open for the whole match. This starts the QuickDraw model on `127.0.0.1:8080`, opens a temporary Cloudflare Quick Tunnel, benchmarks 40/80/160 synthetic drawings through that tunnel, uploads the shared secret and **new tunnel URL** to the existing game Worker, then deploys the Worker. The Vercel frontend already calls this Worker's public URL, so **no Vercel setting needs to change** for the existing game. Restarting the script generates a new tunnel URL and updates the Worker again.

## Requirements for a new clone

- Windows x64, Python **3.10 or 3.11** and Node.js **20+** installed. `py` or `python` and `npm` must be available. The first run automatically creates a Python venv under `%LOCALAPPDATA%\DrawItRight\venv` (short path to avoid TensorFlow's Windows long-path install error), installs pinned requirements and Worker tools, downloads the 60 MB model and Cloudflare's Windows `cloudflared` executable, and generates a local secret. Later runs verify these instead. An existing `model-service/.venv` is also supported.
- The person starting the model must have **write access to the existing Cloudflare account** that owns `draw-it-right-match`. Wrangler may open a browser for login the first time. Cloning alone never grants access to someone else's Worker, and sharing the Cloudflare token or inference secret is not safe. If they use their own Cloudflare/Vercel/Firebase projects, they must first configure those services and the frontend API URL separately.
- The deployed Vercel frontend must point to `https://draw-it-right-match.farrellaxel2006.workers.dev` (the project's current default), and have its normal Firebase setup. Running this script does **not** deploy the frontend or automatically connect another person's Vercel project.
- Internet access must stay on; only **one laptop** should host inference for this Worker at a time. Start it between matches, not in the middle of an active round. Do not let it sleep. Stop with Ctrl+C after the match. When the window closes, the tunnel stops and **live AI judging is unavailable** until the script starts again. Do not start a live match while the model is offline. A Quick Tunnel is for tests/demos, not a production service: https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/

To test a newly cloned setup **without updating the live Worker**, run `start-model.bat -SmokeTest`. That still installs dependencies, starts a temporary tunnel and benchmarks it, then stops both processes. When ready to serve the live game, run `start-model.bat` normally. The console prints `Model is ONLINE` only after Worker deployment **and** an authenticated Worker-to-tunnel health probe succeed. If a command fails, it stops the processes rather than claiming the app is connected.

Secret, model weights, downloaded executable, local Python environment and logs are all ignored by Git. `model-service/.local-secret` is unique to each machine. The startup script never puts its value in command-line arguments; Wrangler accepts it over stdin. Keep it private. If an old laptop is still hosting the game, starting on a new one changes the Worker URL and takes over inference.

## Model and test notes

Model source: https://github.com/idkwhoamitho/DL-Model-GameGuessing, commit `ee23c61b3d07d4afb25eedbbba6f6493aaac146d`. `download-model.py` verifies its SHA-256 on every start. The training notebook uses `inference.py`'s `CLASSES` order, **not** the alphabetical upstream `class_names.json`. The upstream repository has no license; confirm permission before redistribution.

An 800x500 black-on-white JPEG from the canvas is denoised, inverted to white strokes on black, cropped with 10 px padding, resized with OpenCV `INTER_AREA` to 28x28 and normalized. Server replies with top class, its softmax confidence and the target probability. Softmax is not calibrated accuracy: the upstream smiley-face test image was misclassified. Score is calculated by the Worker. Blank and corrupted drawings do not block the whole round.

On this laptop, cold startup to `/health` took about 4.0 seconds. Over the temporary public tunnel, 40 drawings took 0.36 seconds, 80 over two concurrent batches 0.58 seconds, and 160 over four concurrent batches 1.31 seconds (warm, synthetic JPEGs). An isolated Cloudflare edge preview also reached the laptop tunnel with the shared secret. These are **not** 40 real clients or a full authenticated match. Re-run manually with `%LOCALAPPDATA%\DrawItRight\venv\Scripts\python.exe model-service\benchmark.py https://CURRENT-TUNNEL.trycloudflare.com` (or use the repo's existing `model-service/.venv` if present). Python tests: `%LOCALAPPDATA%\DrawItRight\venv\Scripts\python.exe -m unittest discover -s model-service -p 'test_*.py'`. Before a real presentation, run a two-account match and monitor a full 40-player round.
